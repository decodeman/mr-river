# Mr. River

Public long-form dating profile and AI-readable matching surface.

**Current mirror version: 0.13**

The human-facing site is served from `index.html`. `profile.md` is the readable Markdown mirror; `profile.json` and `llms.txt` are machine-readable companions.

The human-facing profile leads with Mr. River's own words before the AI-assisted synthesis. Version 0.13 keeps the presentation couple-first and plainspoken, reduces theatrical language, and treats family as important context rather than the primary organizing frame.

Public media lives under `assets/` in this order: main portrait, water-sport image, hand-on-chin portrait, Jeep/water photo.

The private Kindred repository remains the canonical source; this public repository is the synchronized public mirror and GitHub Pages deployment target.
